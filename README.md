
# โปรเจคตัวอย่าง RAG Pipeline ด้วย Bun, Chonkie, และ DeepSeek

โปรเจคนี้เป็นตัวอย่างที่เรียบง่ายแต่สมบูรณ์ของกระบวนการที่เรียกว่า **Retrieval-Augmented Generation (RAG)** ซึ่งสร้างขึ้นโดยใช้ Bun และ TypeScript โดยจะแสดงวิธีการตอบคำถามจากเอกสารในเครื่องของเรา ด้วยการค้นหาข้อมูลส่วนที่เกี่ยวข้องที่สุด แล้วใช้ Large Language Model (LLM) จากภายนอกมาช่วยสร้างคำตอบที่แม่นยำ

โปรเจคนี้เป็นจุดเริ่มต้นที่ดีเยี่ยมสำหรับทุกคนที่ต้องการทำความเข้าใจกลไกหลักของระบบถาม-ตอบ (Q&A) ด้วย AI สมัยใหม่

## เทคโนโลยีหลักที่ใช้

*   **Runtime**: Bun
*   **ภาษา**: TypeScript
*   **การแบ่งข้อความ (Text Chunking)**: `chonkie`
*   **การสร้าง Embeddings และ Semantic Search**: `@xenova/transformers`
*   **การเชื่อมต่อ LLM**: `openai` (ใช้เป็น client สำหรับ DeepSeek API)
*   **การจัดการ Environment Variables**: `dotenv`

## วิธีการทำงาน: RAG Pipeline

สคริปต์ `deepseek-example.ts` ทำงานตาม 5 ขั้นตอนหลักดังนี้:

1.  **Load & Chunk (โหลดและแบ่งข้อมูล)**: อ่านไฟล์เอกสาร (`.txt`) จากในเครื่อง แล้วใช้ `chonkie` เพื่อซอยย่อยเนื้อหาออกเป็นชิ้นเล็กๆ (chunks) เพื่อให้จัดการได้ง่าย

2.  **Embed (สร้างลายนิ้วมือความหมาย)**: ใช้โมเดลที่รันบนเครื่องผ่าน `@xenova/transformers` เพื่อแปลงเนื้อหาของแต่ละ chunk ให้เป็นชุดตัวเลขที่เรียกว่า "vector embedding" (เปรียบเสมือนลายนิ้วมือทางความหมาย) และทำเช่นเดียวกันกับ "คำถาม" ของผู้ใช้

3.  **Retrieve (ค้นหาข้อมูล)**: ทำการค้นหาแบบ "Semantic Search" โดยการเปรียบเทียบ embedding ของ "คำถาม" กับ embedding ของ "ทุก chunk" เพื่อหาว่า chunk ไหนมีความหมายใกล้เคียงกับคำถามมากที่สุด

4.  **Augment (เสริมข้อมูล)**: เพื่อให้ AI มีบริบทที่สมบูรณ์ขึ้น ระบบจะนำ chunk ที่ดีที่สุดมารวมกับ chunk ข้างเคียง (ก่อนหน้า 2 และหลังจากนั้น 2 รวมเป็น 5 chunks) กลายเป็น "หน้าต่างของบริบท (context window)" แล้วใส่เข้าไปใน prompt ที่จะส่งให้ LLM

5.  **Generate (สร้างคำตอบ)**: ส่ง prompt ที่เสริมข้อมูลแล้ว (ประกอบด้วย context window และคำถามดั้งเดิม) ไปให้ DeepSeek API เพื่อสร้างคำตอบสุดท้ายโดยอิงจากข้อมูลที่ให้ไปเท่านั้น

## วิธีการใช้งาน

### 1. การติดตั้ง

ติดตั้ง library ที่จำเป็นทั้งหมดด้วยคำสั่งของ Bun:

```bash
bun install
```

### 2. ตั้งค่า Environment

โปรเจคนี้ต้องการ API key จากบริการที่เข้ากันได้กับ OpenAI เช่น DeepSeek

ให้สร้างไฟล์ชื่อ `.env` ขึ้นมาที่ root ของโปรเจค แล้วใส่ API key ของคุณ:

```
DEEPSEEK_API_KEY=your_api_key_here
```

### 3. การรันโปรแกรม

รันสคริปต์หลักเพื่อเริ่มกระบวนการ RAG:

```bash
bun run deepseek-example.ts
```

**หมายเหตุ**: ในการรันครั้งแรก โปรแกรมจะทำการดาวน์โหลดโมเดลสำหรับสร้าง embedding (`Xenova/all-MiniLM-L6-v2`) ซึ่งอาจใช้เวลาสักครู่

## การปรับแต่ง

คุณสามารถปรับแต่งสคริปต์ได้อย่างง่ายดายโดยการแก้ไขค่าคงที่ที่ส่วนบนของไฟล์ `deepseek-example.ts`:

*   `userQuestion`: เปลี่ยนเป็นคำถามที่คุณต้องการถามเกี่ยวกับเอกสาร
*   `documentFilename`: เปลี่ยนเป็นชื่อไฟล์เอกสารอื่นที่คุณต้องการใช้
